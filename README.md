# ひとり親ライフチョイス・シミュレータ（single-parent-lifesim）

ひとり親の方、および離婚を考えている方が、**使える制度の取りこぼし**と**これからのお金の見通し**を5分で確かめるための、無料のWebツールです。

非営利団体 **AIかけこみ寺**（NPO法人設立認証申請中）が制作し、**MITライセンス**で公開しています。

---

## このツールの約束

**どんな状況でも、次の一手が見えること。**

このツールは「あなたは詰んでいます」で終わりません。入力がどんな内容でも、資産カーブの直下に「**あなたの場合の道筋**」を必ず出します。次の一手と、それを打つと数字がどう動くかを、セットで示します。

- 未申告の制度があれば「申請すると毎月◯円ふえて、黒字になります」
- すでに全部使っていれば「生活防衛資金への到達が◯か月早まります」「次は学費の山です」
- 収入が低ければ「資格を取る道なら◯年後に追い越します」（グラフに3本目の線が出ます）
- 数字がどうしても足りなければ「**生活保護は、負けではありません。やり直すための土台です**」

この「道筋」ブロックが空になることは、設計上ありません。**サンプル6件すべてと、収入0円の極端な入力について、自動テストで固定しています。**

## ⚠ はじめに必ずお読みください

> **このツールが出す金額は、すべて概算です。正確な額は、お住まいの市区町村の窓口で確認してください。**

- 本ツールは**無保証**です。制作者・提供者は、本ツールの利用によって生じたいかなる損害についても責任を負いません。
- 収載しているのは**全国共通の制度だけ**です。自治体独自の制度（ひとり親医療費助成、水道料金の減免など）は判定できません。
- **財産分与・年金分割・慰謝料はスコープ外**です。金額の差は数百万円になり得ます。必ず法律の専門家（法テラス等）に相談してください。
- 制度の内容は年度ごとに変わります。各制度カードに表示している**最終確認日**より前の情報にもとづいています。

### DVの当事者の方へ

全画面の右上に**「すぐ閉じる」ボタン**があります（キーボードの Esc キーでも同じ）。押すと即座に天気予報のページへ切り替わり、`location.replace` を使っているため、いま見ていたページとして履歴に残りにくくしてあります。閲覧履歴そのものを消す方法は `manual.html` に書いてあります。

### 収載している制度（17件）

児童扶養手当 ／ 児童手当 ／ ひとり親控除・寡婦控除 ／ 就学援助 ／ 高等職業訓練促進給付金 ／ 自立支援教育訓練給付金 ／ 国民健康保険料の軽減・減免 ／ 国民年金保険料の免除・猶予 ／ 公営住宅の優先入居 ／ 母子父子寡婦福祉資金貸付金 ／ 高等学校等就学支援金・高校生等奨学給付金 ／ 高等教育の修学支援新制度 ／ 住居確保給付金 ／ 生活保護 ／ 養育費の取り決めと強制執行 ／ ファミサポ・病児保育・ショートステイ ／ **食の支援（こども食堂・フードバンク・フードパントリー）** ／ DV関連（住民票の閲覧制限・保護命令・相談窓口）

### 生活防衛資金の「3〜6か月分」について

このツールは「生活費の3〜6か月分を先に貯める。そこに届くまで投資は考えなくていい」と断言しています。根拠の種類を分けて書いています。

- **事実（出典あり）**: 金融庁「家計管理の基本は、収入と支出をきちんと把握・管理すること、収支を黒字にすること、そして黒字分を貯蓄することです」／金融広報中央委員会「金額は生活費の半年分が目安です」
- **当団体の立場表明（出典なし）**: 「3か月分から6か月分」という幅そのもの、および「そこに届くまで投資は考えなくていい」という優先順位の主張

**金融庁は「生活費の3〜6か月分」という具体的な数字は示していません。**画面上でも、事実と立場表明を灰色の枠で分けて表示しています。

### 児童扶養手当の精度について

自動判定する3件のうち、児童扶養手当は令和8年度の以下を実装しています。

- 給与収入 → 給与所得（給与所得控除。令和7年分以降の速算表）
- 給与所得者の一律10万円控除、社会保険料相当額8万円の控除
- **養育費の8割算入**
- 扶養親族等の数（0〜5人＋外挿）ごとの、全部支給・一部支給の所得制限限度額
- 一部支給の傾斜式：`本体 = 48,050 −〔(所得額 − 全部支給限度額) × 0.0264029 ＋ 10円〕`（10円未満四捨五入）、加算は同型で係数 0.0040719

こども家庭庁が公開している公式の計算例（給与収入181万円・養育費年30万円・扶養1人 → **44,080円**）と、**1円まで一致する**ことをテストで固定しています。

## 動かし方

完全な静的サイトです。サーバーもデータベースも使いません。入力した内容は**あなたのブラウザの中だけ**で処理され、インターネットに送信されることも、端末に保存されることもありません（localStorage も使っていません）。

### いちばんかんたんな方法

**`index.html` をダブルクリックするだけです。**インターネットにつながっていなくても動きます。

制度データも画面と一緒に読み込む形にしてあるので、`file://` で直接開いても全機能が動きます（jsdom による自動チェックで、ファイル直開きの状態でも制度カード17枚・グラフ・注意書き・AI相談用の文章5本がすべて出ることを確認しています）。

### ローカルサーバーを立てる場合

改造して試すときなど、必要であれば次のようにもできます。

**Mac（zsh）／Linux:**

```bash
cd single-parent-lifesim
python3 -m http.server 8000
```

**Windows（PowerShell）:**

```powershell
cd single-parent-lifesim
python -m http.server 8000
```

そのあとブラウザで <http://localhost:8000/> を開きます。

### 段階開示のながれ

1. **貯金は、どうたまっていくか（最初の出力）** — 月次収支を末子22歳まで累積した資産カーブ
   - 起点は**いまの貯金額**。線は2本：**いまのまま／使える制度を全部使った場合**
   - 冒頭に「まだ使っていない制度で、10年で約◯◯万円変わります」を大きく出し、**「この差の中身を見る」で制度一覧へ**つなぎます
   - **生活防衛資金ゾーン**（生活費×3〜6か月分）を帯で表示。到達時期を「約◯年◯か月」で表示。すでに帯を越えている人には「次の段階を考えはじめてもよい段階です」＋AI相談への導線
   - **学費**を該当年齢の年に差し引きます。進路を変えるとその場で再描画し、「全部公立との差: 累計約◯◯万円」を表示
   - **赤字になる場合は「毎月あと◯円足りない状態です」を主役に**し、累積額は前に出しません。グラフはマイナス突入後3年ぶんで打ち切り、その先は網かけ＋「このままの前提では成り立たない領域」の注記にします（借金は積み増せず、その前に人は行動を変えるため、22歳までの直線外挿は予測として不誠実だからです）
   - **グラフの床は「貸金業法の総量規制（年収の3分の1）」**。赤い破線で「法律上、これ以上は借りられません」と示し、縦軸もそこまでに制限します。年収150万円の人に「マイナス500万円」の目盛りを見せても、そんな金額は実際に借りられないためです
   - **「資格を取るルート」**（むらさきの線）を重ねられます。訓練中（1〜4年）は収入が下がる代わりに高等職業訓練促進給付金が入り、修了後は入力した見込み年収へ。「◯年後に追い越します」「逆転しません」を正直に表示します
   - 直下に**不足を埋める手の一覧**（養育費の取り決め／未申告制度／就学援助／食の支援／住居費／就労支援／生活保護／相談窓口）を、各制度カードへのリンクつきで出します。**不足が月1万円未満のときは「今週から動けるもの」を上位**に並べ替え、「借金では埋められません」を明記
2. **使えるかもしれない制度** — 「対象の可能性が高い」「窓口で確認したいもの」「対象外の見込み」に分類。**すでに使っていると申告したものは「✓ 利用中」**になり、未利用の該当制度だけが目立ちます
3. **続けた場合と、離婚した場合のくらべ方** — **ひとりあたりに直した金額（等価可処分所得）**が主表示。家全体の金額にも切替可。制度の崖を縦線でマーク。「お金の話だけ」注記とDV導線つき
4. **気をつけてほしいこと** — 「まずやること」チェックリスト＋「落とし穴チェック」。長い解説は折りたたみ
5. **AIに相談するための文章** — 5本、コピーボタンつき

## 資格を取って抜けるルートについて

低収入のケースで年収固定のまま外挿すると、グラフは「詰み」しか示しません。それは事実ではないので、脱出ルートを同じグラフに描けるようにしています。

| 項目 | 扱い |
|---|---|
| 訓練期間 | 1〜4年（既定2年） |
| 訓練中の働き方 | **「働かない（0円）」「いまの半分（既定）」「いまのまま」「自分で入れる」の4択**。選ぶとその場で線が引き直されます。看護師などフルタイム課程は両立が難しい旨を注記 |
| 給付金 | 高等職業訓練促進給付金 月100,000円（住民税非課税）／70,500円（課税）、最後の12か月は+40,000円、修了時に50,000円（課税25,000円） |
| 非課税判定 | 訓練中の給与所得135万円以下を非課税と**仮定**（実際の判定は市区町村） |
| 修了後の年収 | **利用者が入力**。このツールは職種別の平均年収を示しません |

**職種別の賃金プリセットは載せていません。**賃金構造基本統計調査の職種別データを一次資料で取得できなかったためです（e-Statの該当ファイルが404）。相場は「仕事・収入の相談」プロンプトでAIに調べてもらう導線にしています。**取得できしだいプリセット化するのが今後の課題です。**

社会的証明として、実績を1行で添えています（令和5年度: 資格取得2,988人、うち看護師945人・准看護師686人・保育士245人、就職2,105人／自治体実施率97.2%）。出典はこども家庭庁「ひとり親家庭等の支援について」（令和7年4月）。

## このグラフの前提（画面に常設）

資産カーブの直下に「このグラフの前提」ボックスを常設し、**甘く出るところも正直に**書いています。

- 収入は、いまのまま変わらない前提（昇給・転職なし。資格ルートのみ例外）
- **生活費は、いまと同じ金額がずっと続く前提。**実際にはお子さんが中高生になると食費などが増えるため、**後半の線は甘め（実際より良く）に出ます**（この一文は画面上で強調表示）
- 学校にかかるお金は全国の平均値（中央値ではない）
- 手当は毎年その年の子の年齢で計算し直し（グラフの段差の正体）
- 物価上昇・今後の制度改正は未反映

### 子どもの成長による生活費の増額係数について

**係数は入れていません。**一次資料で組めなかったためです。試したのは次の3つで、いずれも数値を確認できませんでした。

| 試した資料 | 結果 |
|---|---|
| 内閣府「子育て費用に関する調査」 | 最新版が平成21年度で、現在値として使うには古い |
| 家計調査の子の年齢別の食料支出 | 該当するクロス集計を確認できず |
| 厚労省「日本人の食事摂取基準（2025年版）」推定エネルギー必要量 | **PDFの該当表が画像で、数値を機械的に読み取れず**（表の存在と参照表番号は確認済み） |

推測した係数を入れると、根拠のない数字がグラフの形を決めてしまいます。そこで**増額はせず、代わりに「後半は甘めに出る」ことを画面に明記する**方針にしました。お子さんが大きくなったときの姿を見たい方には、生活費の欄を多めに入れて試す方法を案内しています。

## 学費データについて

進路プランごとに、該当年齢の年から差し引きます。**すべて全国の平均値**であり、中央値ではありません（画面にも明記）。

| 段階 | 公立 | 私立 |
|---|---|---|
| 小学校（6〜11歳） | 366,599円/年 | 1,741,516円/年 |
| 中学校（12〜14歳） | 542,450円/年 | 1,560,359円/年 |
| 高校（15〜17歳） | 596,954円/年 | 1,179,261円/年 |

| 大学（18〜21歳） | 年額 | 入学料（初年度のみ） |
|---|---|---|
| 国立・自宅 | 639,200円 | 282,000円 |
| 国立・ひとり暮らし | 1,800,700円 | 282,000円 |
| 私立・自宅 | 1,399,100円 | 240,365円 |
| 私立・ひとり暮らし | 2,689,100円 | 240,365円 |

- 小中高：文部科学省「令和5年度 子供の学習費調査」の**学習費総額**（学校教育費＋学校給食費＋学校外活動費）。**令和8年1月16日の訂正版**の数値
- 大学：日本学生支援機構「令和6年度 学生生活調査」。**自宅は「学費」のみ、ひとり暮らしは「学生生活費」（学費＋生活費）**。自宅通学の食費等は毎月の生活費に含まれているとみなし、二重計上を避けています
- 入学料：国立は文科省令の標準額、私立は文科省「私立大学等の令和7年度入学者に係る学生納付金等調査結果」の平均額
- 幼稚園・保育園（0〜5歳）：幼児教育・保育の無償化を踏まえ**0円**として計算（注記あり）
- 高校：金額は授業料込みの平均のため、就学支援金（公立118,800円／私立457,200円）で実際の負担は軽くなる旨を注記

**二重計上を避けるため、生活費の入力欄は「毎月の生活費（住居費と、学校にかかるお金をのぞく）」**というラベルにしています。

### 生活費のうちわけ（任意）

生活費の欄の下に、折りたたみで費目別（食費／水道・光熱費／通信費／保険料／そのほか）を入れられます。入れると合計が生活費欄に自動反映され、費目ごとの割合と「見直しの候補」が出ます。

**よその家庭の平均とは比べていません。**世帯人員や地域で大きく変わるうえ、比較に使える一次資料（家計調査のひとり親世帯の費目別内訳）を確認できなかったためです。出しているのは、入力された金額の中での割合だけです。トーンは断言ではなく「見直しの候補」で、個別の商品名は出しません。

## テスト

```bash
node test/run.js
```

追加のパッケージは要りません。948件のチェックが走ります。おもな内容:

- 給与所得控除の区分の境目（190万円ちょうど／1円超、360万円ちょうど／1円超、上限）
- 児童扶養手当の所得額（養育費8割算入、一律10万円控除、社会保険料相当8万円）
- **判定の境目**: 扶養0〜4人それぞれについて、全部支給限度額 ±1円、一部支給限度額 ±1円
- 一部支給の傾斜式（公式計算例との1円一致、上限48,040円、下限11,340円、単調減少）
- 児童手当の第3子カウント（22歳年度末までを数え、19歳以上は支給対象外）
- 年次シミュレーション（制度の崖の年齢で金額が変わること、親支援終了スライダーで崖が動くこと）
- **ひとりあたりに直した金額（等価可処分所得。÷√世帯人数）** の計算、世帯人数の割り当て、家全体の金額で比べたときより差が縮まること
- **資産カーブ**の累積計算（1年目＝月次×12、2年目以降が積み増されること）、いまの貯金を起点にすること、すでに使っている制度の差分計算、生活防衛資金への到達月数、赤字ケースで0に切られずマイナスのまま出ること
- **学費**の年齢帯判定、入学料が初年度だけ加算されること、進路プラン別の累計差、**生活費と学費が1回ずつしか引かれていないこと（二重計上がないこと）**、学費データの出典が官公庁ドメインであること
- 赤字時の打ち切り（マイナス突入から3年ぶん、または**借りられる上限に達した時点**の早いほうで止まること、月次不足額を持つこと）
- **借入の床**（年収の3分の1でクランプされること、床のラベルと赤破線が出ること、縦軸が床より深くならないこと）
- **資格ルート**（訓練中の給付金加算・最終年の上乗せ・修了後のジャンプ・逆転年の計算・逆転しないケースを正直に返すこと・課税/非課税の分岐・3本目の線が描かれること）
- **「あなたの場合の道筋」が空にならないこと**（サンプル6件それぞれで固有の道筋が2つ以上出ること、数字とリンクがともなうこと、収入0円では生活保護が「権利」として出ること）
- **スマホの縦長レイアウト**（360×470、たて/よこ比1.2〜1.6倍、全サンプル×3種のグラフで文字の衝突ゼロ・左右にはみ出さないこと）
- 記入例の適用でスクロールしないこと、値が入った欄が色づくこと、「この内容で見てみる」では結果まで送ること
- **グラフの文字の当たり判定**: SVGのテキストの座標と推定幅から重なりを機械的に検出。全サンプル×2種のグラフで衝突ゼロを検証。縦軸の目盛りが2〜7本におさまり、半端な小数が出ないこと、375px幅で文字がはみ出さないこと、文字が10px以上あること
- サンプル6件のスナップショット（判定区分・概算額・所得額・出る注意書きの顔ぶれ）
- 制度データの点検（17件すべてに条文名・**官公庁ドメインの https URL**・最終確認日があること）
- 外部通信をしていないこと、localStorage を使っていないこと、読み込みに通信を使っていないこと（`file://` で直接開いても動くこと）

