# ひとり親ライフチョイス・シミュレータ（single-parent-simulator）

ひとり親の方、および離婚を考えている方が、**使える制度の取りこぼし**と**これからのお金の見通し**を5分で確かめるための、無料のWebツールです。

非営利団体 **AIかけこみ寺**（NPO法人設立認証申請中）が制作し、**MITライセンス**で公開しています。

---

## ⚠ はじめに必ずお読みください

> **このツールが出す金額は、すべて概算です。正確な額は、お住まいの市区町村の窓口で確認してください。**

- 本ツールは**無保証**です。制作者・提供者は、本ツールの利用によって生じたいかなる損害についても責任を負いません。
- 収載しているのは**全国共通の制度だけ**です。自治体独自の制度（ひとり親医療費助成、水道料金の減免など）は判定できません。
- **財産分与・年金分割・慰謝料はスコープ外**です。金額の差は数百万円になり得ます。必ず法律の専門家（法テラス等）に相談してください。
- 制度の内容は年度ごとに変わります。各制度カードに表示している**最終確認日**より前の情報にもとづいています。

### DVの当事者の方へ

全画面の右上に**「すぐ閉じる」ボタン**があります（キーボードの Esc キーでも同じ）。押すと即座に天気予報のページへ切り替わり、`location.replace` を使っているため、いま見ていたページとして履歴に残りにくくしてあります。閲覧履歴そのものを消す方法は `manual.html` に書いてあります。

## 収めている内容

| | 件数 |
|---|---|
| 制度 | **17件**（うち入力から自動判定する制度 3件／窓口での確認にまわす制度 14件） |
| 注意喚起 | **11件**（赤5件／黄6件） |
| サンプル（架空の例） | **6件** |
| 自動チェック | **473件**（`node test/run.js`）＋ 画面のチェック **20件**（`node test/ui.js`。jsdom がある場合のみ） |

### 収載している制度（17件）

児童扶養手当 ／ 児童手当 ／ ひとり親控除・寡婦控除 ／ 就学援助 ／ 高等職業訓練促進給付金 ／ 自立支援教育訓練給付金 ／ 国民健康保険料の軽減・減免 ／ 国民年金保険料の免除・猶予 ／ 公営住宅の優先入居 ／ 母子父子寡婦福祉資金貸付金 ／ 高等学校等就学支援金・高校生等奨学給付金 ／ 高等教育の修学支援新制度 ／ 住居確保給付金 ／ 生活保護 ／ 養育費の取り決めと強制執行 ／ ファミサポ・病児保育・ショートステイ ／ DV関連（住民票の閲覧制限・保護命令・相談窓口）

制度データは1件ずつ、**条文名＋官公庁の一次資料URL＋最終確認日**を持っています。画面の各制度カードにも表示されます。

### 児童扶養手当の精度について

自動判定する3件のうち、児童扶養手当は令和8年度の以下を実装しています。

- 給与収入 → 給与所得（給与所得控除。令和7年分以降の速算表）
- 給与所得者の一律10万円控除、社会保険料相当額8万円の控除
- **養育費の8割算入**
- 扶養親族等の数（0〜5人＋外挿）ごとの、全部支給・一部支給の所得制限限度額
- 一部支給の傾斜式：`本体 = 48,050 −〔(所得額 − 全部支給限度額) × 0.0264029 ＋ 10円〕`（10円未満四捨五入）、加算は同型で係数 0.0040719

こども家庭庁が公開している公式の計算例（給与収入181万円・養育費年30万円・扶養1人 → **44,080円**）と、**1円まで一致する**ことをテストで固定しています。

## 動かし方

完全な静的サイトです。サーバーもデータベースも使いません。入力した内容は**あなたのブラウザの中だけ**で処理され、インターネットに送信されることも、端末に保存されることもありません（localStorage も使っていません）。

制度データを読み込む都合上、**HTMLファイルを直接ダブルクリックして開く（`file://`）と動きません**。かんたんなローカルサーバーを立てて開いてください。

**Mac（zsh）／Linux:**

```bash
cd single-parent-simulator
python3 -m http.server 8000
```

**Windows（PowerShell）:**

```powershell
cd single-parent-simulator
python -m http.server 8000
```

**Node.js を使う場合:**

```bash
npx --yes http-server -p 8000
```

そのあとブラウザで <http://localhost:8000/> を開きます。

## 画面の説明

| ファイル | 内容 |
|---|---|
| `index.html` | 入力フォーム → 使える制度 → くらべるグラフ → 気をつけたいこと → AIに相談する文章 |
| `manual.html` | **使い方マニュアル**。動作例、機械にできないこと、情報がどこに行くか、AIに改造を頼むためのプロンプト |

**操作方法がわからないときは、まず [`manual.html`](manual.html) を開いてください。**

### 段階開示のながれ

1. **使えるかもしれない制度** — 「対象の可能性が高い」「窓口で確認したいもの」「対象外の見込み」の3つに分けて表示
2. **くらべるグラフ** — 婚姻継続と離婚後の、ひと月あたりに使えるお金を、いちばん下のお子さんが22歳になるまで年次で比較。制度の崖と、親からの援助が終わる時期を縦線でマーク
3. **気をつけてほしいこと** — 赤（強い警告）と黄（確認してほしいこと）。赤は「事実（官公庁の出典つき）」と「当団体の立場表明」を画面上で分けて表示
4. **AIに相談するための文章** — キャリア／お金の守り方／保険／地域の制度／引っ越し の5本。コピーボタンつき

## フォルダの構成

```
index.html        画面
manual.html       使い方マニュアル
css/style.css     見た目
js/engine.js      計算のしんぶ（金額は持たない。計算のやり方だけ）
js/chart.js       グラフの描画（自前のSVG。外部ライブラリなし）
js/prompts.js     AIに相談する文章の組み立て
js/app.js         画面のうごき
data/programs.json  制度データ（17件。金額・限度額・出典はすべてここ）
data/pitfalls.json  注意喚起データ（11件）
data/samples.json   架空の例6件。画面の「例で試す」とテストが同じ数字を共用
test/run.js       自動チェック（Node.jsのみ。追加パッケージ不要）
test/ui.js        画面を実際に動かすチェック（jsdom があれば動く。なければ自動で飛ばす）
```

**制度改正が来たときは、`data/programs.json` の数字を直すだけで対応できます。**計算のやり方（`js/engine.js`）には金額を書いていません。直したら必ずテストを走らせてください。

## テスト

```bash
node test/run.js
```

追加のパッケージは要りません。473件のチェックが走ります。おもな内容:

- 給与所得控除の区分の境目（190万円ちょうど／1円超、360万円ちょうど／1円超、上限）
- 児童扶養手当の所得額（養育費8割算入、一律10万円控除、社会保険料相当8万円）
- **判定の境目**: 扶養0〜4人それぞれについて、全部支給限度額 ±1円、一部支給限度額 ±1円
- 一部支給の傾斜式（公式計算例との1円一致、上限48,040円、下限11,340円、単調減少）
- 児童手当の第3子カウント（22歳年度末までを数え、19歳以上は支給対象外）
- 年次シミュレーション（制度の崖の年齢で金額が変わること、親支援終了スライダーで崖が動くこと）
- サンプル6件のスナップショット（判定区分・概算額・所得額・出る注意書きの顔ぶれ）
- 制度データの点検（17件すべてに条文名・**官公庁ドメインの https URL**・最終確認日があること）
- 外部通信をしていないこと、localStorage を使っていないこと

さらに、jsdom を入れてあれば、画面そのものを動かすチェック（20件）も走ります。

```bash
npm install jsdom   # このリポジトリ自体は依存パッケージなしのままです
node test/ui.js     # jsdom がなければ、何もせず終わります
```

制度カードが17枚出ること、出典リンクと最終確認日が付くこと、グラフの線が2本描かれること、立場表明が事実と分けて表示されること、親支援のつまみを動かすと崖が動くこと、画面の操作でエラーが出ないことを確かめます。
